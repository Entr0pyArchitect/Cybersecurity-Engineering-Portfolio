# Security Policy

## Reporting a Security Issue

If you believe you found a security issue in this repository, avoid posting sensitive details in a public issue.

Report sensitive findings privately to:

**Entr0pyArchitect@proton.me**

For non-sensitive documentation bugs, broken links, formatting issues, or clearly harmless defects, a normal GitHub issue is appropriate.

## Scope

This repository is a cybersecurity engineering portfolio and contains experimental, educational, lab-oriented, and scaffold-stage projects. Unless a project README explicitly states otherwise:

- code is not presented as production-ready;
- projects are intended for owned systems, synthetic data, designated training environments, or explicitly authorized targets;
- no warranty is made regarding suitability for protecting critical systems or data.

## Disclosure Guidance

Please include the affected project/path, concise reproduction steps, expected versus observed behavior, relevant version/commit, impact assessment, and suggested remediation if known.

Do not include real credentials, private keys, customer data, active CTF flags, or unrelated personal information.
