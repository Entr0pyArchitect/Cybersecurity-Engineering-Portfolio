This directory contains the certification-preparation track of the **Cybersecurity Engineering Portfolio**.

The goal is not simply to pass exams. Each certification track is intended to combine structured study, official objectives, hands-on practice, review, and practical validation so the knowledge carries directly into security engineering work.

> **Preparation does not imply completion.** A certification will only be listed as earned after it has actually been obtained.

---

## Certification Roadmap

| Certification | Primary Purpose | Portfolio Connection |
|---|---|---|
| **CompTIA Security+** | Build a broad cybersecurity foundation | Security fundamentals, architecture, operations, identity, risk, and incident response |
| **Cisco CCNA** | Strengthen networking and infrastructure knowledge | Routing, switching, addressing, segmentation, troubleshooting, and network security fundamentals |
| **CompTIA CySA+** | Develop defensive-analysis and SOC-oriented skills | Detection engineering, SIEM, DFIR, threat intelligence, vulnerability management, and incident response |
| **OffSec OSCP+** | Build practical penetration-testing methodology | Authorized offensive security, enumeration, exploitation, privilege escalation, Active Directory, and technical reporting |

## CompTIA Security+ Preparation

Directory:

```text
CompTIA Security+ Prep/
```

Security+ is the broad security-foundation track of this roadmap.

Preparation will focus on areas such as:

- security concepts and terminology;
- threats and vulnerabilities;
- authentication and identity;
- security architecture;
- cryptography fundamentals;
- network and endpoint security;
- security operations;
- incident response;
- governance, risk, and compliance;
- vulnerability and risk management.

The objective is to connect foundational concepts with the engineering projects throughout the portfolio.

---

## Cisco CCNA Preparation

Directory:

```text
Cisco CCNA Prep/
```

The CCNA track focuses on developing the networking knowledge required to understand how systems communicate and how infrastructure behaves under normal and abnormal conditions.

Preparation will include:

- IPv4 and IPv6;
- subnetting;
- Ethernet and switching;
- VLANs and trunking;
- spanning tree;
- routing;
- DHCP, DNS, and NAT;
- wireless fundamentals;
- access control;
- network-security fundamentals;
- automation and programmability;
- troubleshooting.

Hands-on work should emphasize configuration, packet analysis, topology reasoning, and troubleshooting rather than command memorization alone.

## CompTIA CySA+ Preparation

Directory:

```text
CompTIA CySA+ Prep/
```

CySA+ is the defensive-analysis component of the roadmap.

This track connects directly with portfolio work involving telemetry, SIEM engineering, detection engineering, DFIR, vulnerability management, and threat intelligence.

Preparation will include:

- security operations;
- alert and event analysis;
- log analysis;
- threat intelligence;
- threat hunting concepts;
- vulnerability management;
- prioritization and remediation;
- incident response;
- endpoint and network telemetry;
- analysis and reporting.

Hands-on exercises will remain within synthetic, owned, or explicitly authorized environments.

---

## OffSec OSCP+ Preparation

Directory:

```text
OffSec OSCP+ Prep/
```

OSCP+ preparation will focus on practical penetration-testing methodology within **isolated labs, CTFs, owned systems, and explicitly authorized environments only**.

Preparation will include:

- reconnaissance and enumeration;
- service analysis;
- vulnerability identification;
- controlled exploitation;
- Linux privilege escalation;
- Windows privilege escalation;
- Active Directory methodology;
- pivoting and network-path reasoning;
- evidence collection;
- technical note-taking;
- professional reporting;
- cleanup and lab reset procedures.

The objective is not to memorize individual exploits. The goal is to develop a repeatable methodology for discovering, validating, documenting, and communicating security weaknesses responsibly.

## Documentation Standard

Public study material should be:

- written in my own words;
- technically accurate;
- organized for future review;
- based primarily on official vendor objectives and documentation;
- supported by hands-on validation where appropriate;
- clear about the difference between theory and demonstrated behavior.

---

## Exam Integrity

This repository will not contain:

- exam dumps;
- braindumps;
- stolen exam questions;
- recalled live exam content;
- unauthorized answer keys;
- copyrighted training material reproduced wholesale.

The goal is genuine understanding and practical capability.

---

## Security & Lab Scope

Security testing performed during certification preparation is limited to:

- personally owned systems;
- isolated virtual machines;
- intentionally vulnerable training environments;
- CTF platforms where the activity is permitted;
- explicitly authorized systems.

Real credentials, unauthorized targets, and private third-party data do not belong in this workspace.
