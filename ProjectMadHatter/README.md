**Project MadHatter** is the roadmap and execution system behind the Cybersecurity Engineering Portfolio.

The program began on **14 May 2026** and remains open-ended. It connects hands-on engineering, structured learning, CTF practice, documentation, and evidence into one long-term system.

## Operating Doctrine

> **Build → Learn → Practice → Document → Prove**

The program uses one primary implementation lane at a time. Supporting projects may collect source notes, schemas, or small artifacts, but substantial implementation should remain focused.

## Public Documentation

- [`Documentation/README.md`](Documentation/README.md) — public-safe overview of the program documentation boundary.

Detailed MadHatter planning manuals remain available locally but are intentionally excluded from public Git history.

## Current Direction

- **Project 01 — TripplePulsarVault:** completed anchor project.
- **Project 02 — Threat-Informed Defense Platform:** current implementation lane.
- **Projects 02–17:** established development projects/scaffolds at different maturity levels.
- **Project 18 — Private Security Research Capstone:** maintained locally; implementation and planning material are excluded from public Git history.

## Technical Authorship

Project code, challenge solutions, troubleshooting, and technical reasoning remain independently authored by the builder. AI may assist with organization, formatting, planning, source checking, and review, but it should not replace hands-on technical work or fabricate evidence.

## Public / Private Boundary

The public repository contains only material appropriate for external review. Raw evidence, sensitive environment details, private research implementation, and detailed operational planning remain local unless deliberately sanitized for publication.

## Review Cycle

- **Weekly:** review evidence, blockers, current limitations, and the next smallest useful action.
- **Every 90 days:** decide whether the active lane should continue, narrow, pause, or close a defined milestone.
- **Before public release:** verify claims, scope, evidence, secret hygiene, screenshots, CTF rules, and limitations.
