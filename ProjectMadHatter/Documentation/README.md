# Project MadHatter — Public Documentation

This directory is the public documentation boundary for **Project MadHatter**, the execution framework behind the Cybersecurity Engineering Portfolio.

## Publicly documented

The public repository documents:

- the doctrine **Build → Learn → Practice → Document → Prove**;
- the current public implementation lane;
- project maturity and evidence standards;
- review cadence;
- legal and ethical scope;
- the distinction between demonstrated behavior and planned capability.

## Intentionally local-only

Detailed planning manuals, raw evidence, private research implementation, environment-specific notes, and other operational material remain outside public Git history unless deliberately sanitized for publication.

This boundary is intentional: the portfolio should prove engineering ability without publishing information that does not need to be public.
