# Project Charter

## Project
11-Active-Directory-Purple-Team-Range

## Purpose
Create a synthetic Active Directory purple-team range model focused on defensive detections, group-change review, service-account risk, and evidence.

## Scope
This MVP uses local synthetic data and safe validation logic only.

## Non-Goals
- No unauthorized third-party testing
- No real secrets or private data
- No destructive actions
- No production deployment
- No claims without evidence

## Success Criteria
- Validation pipeline runs locally.
- Expected positive and negative controls behave correctly.
- Evidence is captured.
- Documentation explains scope, assumptions, and limitations.
