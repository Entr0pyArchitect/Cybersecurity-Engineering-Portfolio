# Source Map

Use official or primary sources first.

## Core References
- NIST Computer Security Incident Handling Guide SP 800-61 Rev. 2: https://csrc.nist.gov/publications/detail/sp/800-61/rev-2/final
- CISA Cybersecurity Incident Response Resources: https://www.cisa.gov/resources-tools/resources/incident-response-resources
- MITRE ATT&CK Enterprise: https://attack.mitre.org/
- Go Documentation: https://go.dev/doc/
- NIST Cybersecurity Framework: https://www.nist.gov/cyberframework

## Source Rules
- Prefer official guidance.
- Keep response actions reversible and human-approved.
- Document the difference between planning and executing a response.
- Do not claim real containment unless evidence proves it in an owned lab.
