# Design Notes

## MVP Architecture

synthetic inputs -> validation pipeline -> JSON report -> evidence

## Current Design
This project starts with safe local inputs and deterministic validation.

## Why Start Synthetic
Synthetic data gives clear expected outcomes and avoids unsafe assumptions before live-lab work is introduced.

## Connected MadHatter Role
Build a read-only DFIR evidence workflow using synthetic evidence files, hashes, manifests, and chain-of-custody documentation.
