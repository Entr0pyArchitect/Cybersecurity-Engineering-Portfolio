# Project Charter

## Project
02-Threat-Informed-Defense-Platform

## Purpose
Build a lab-safe defensive orchestration platform that converts mock or public threat-intelligence style inputs into ATT&CK-mapped detection backlog items, telemetry requirements, and candidate detection ideas.

## Scope
This project is defensive, educational, and lab-bounded. It does not attack real systems, scrape private data, run exploits, or automate offensive action.

## Non-Goals
- No real-world targeting
- No credential collection
- No malware execution
- No autonomous response action in this project
- No production deployment

## Success Criteria
- API runs locally
- Health endpoint works
- Mock TTP input can be ingested
- Techniques are mapped to tactics and telemetry requirements
- Output is readable as a detection engineering backlog
- README and evidence are recruiter-readable
